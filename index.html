CẢNH BÁO CẤP CỨU NHI KHOA (RED FLAGS ALERT)

Nhận diện "Dấu hiệu Cờ Đỏ" Cần Đưa Con Đến Viện Ngay Lập Tức

Cấp cứu 24/7
1. Thở co rút lồng ngực

Phần dưới lồng ngực lõm sâu vào khi bé hít vào, cánh mũi phập phồng.

2. Thở rít / Tím tái

Tiếng thở rít khi nằm yên, môi hoặc đầu ngón tay nhợt nhạt, tím tái.

3. Giật mình chới với

Giật mình nảy người lúc thiu thiu ngủ, run chi, đi loạng choạng (Dấu hiệu Tay chân miệng nặng).

4. Li bì khó đánh thức

Bé ngủ li bì, gọi hỏi ít đáp ứng, bỏ bú hoặc không uống được nước.

5. Nôn tất cả mọi thứ

Nôn liên tục, đau bụng vùng gan, chảy máu mũi/chân răng (Cảnh báo Sốt xuất huyết).

6. Chân tay lạnh ẩm

Bàn tay bàn chân lạnh ẩm, da nổi vân tím hoặc co giật toàn thân.

  2. Nhấn nút "📋 Sao chép toàn bộ Code.gs" ở mục số 2 phía trên và dán đè vào tệp Code.gs.
  3. Chọn hàm setup trên thanh công cụ rồi nhấn Chạy (Run) và cấp quyền Google Drive/Sheets. Hệ thống sẽ tự động tạo tệp [CSDL_PediaInfect_Clinical_HNH] với đầy đủ 5 Sheets chuẩn và 100 Ca bệnh mẫu Bộ Y tế.
  4. Nhấn Triển khai (Deploy) → Tùy chọn triển khai mới (New deployment) → Ứng dụng web (Web app).
  5. Chọn Execute as: Me (anhtran.nihbt@gmail.com) và Who has access: Anyone (Bất kỳ ai) (để trình duyệt gọi fetch API không bị chặn CORS; quyền truy cập thực tế đã được khóa chặt bởi lớp xác thực User + Password và Access_Expires_At trong doPost).
  6. Sao chép URL https://script.google.com/macros/s/.../exec.

BƯỚC 2: TRIỂN KHAI LÊN GITHUB PAGES (TÀI KHOẢN: GITHUB.COM/ANH-GENETICS)
  1. Dán URL /exec của Bước 1 vào ô Google Apps Script API Endpoint URL ở mục số 1 phía trên rồi nhấn nút "⬇ Tải file index.html đã nhúng sẵn API URL".
  2. Trên trang github.com/Anh-Genetics, nhấn dấu (+) → New repository ở góc trên bên phải.
  3. Đặt tên Repository đồng bộ hệ sinh thái TTA_ của bạn: TTA_PediaInfect-clinical → chọn Public → tích chọn Add a README file → nhấn Create repository.
  4. Trong kho lưu trữ vừa tạo, nhấn Add file → Upload files → kéo thả tệp index.html vừa tải về (và tệp .nojekyll trong gói ZIP) vào → nhấn nút xanh Commit changes.
  5. Vào tab Settings → chọn mục Pages ở cột menu bên trái → tại mục Branch, đổi từ None sang main (thư mục /root) → nhấn Save.
  6. Sau 30–60 giây, ứng dụng chính thức hoạt động tại địa chỉ riêng sạch 100%: https://anh-genetics.github.io/TTA_PediaInfect-clinical/
